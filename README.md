# Simple-Chatbot# 🤖 Simple Chatbot

## 📌 Project Description

**Simple Chatbot** is a basic web-based chatbot that interacts with users through text messages. It provides predefined responses to common questions and creates a simple conversational experience.

## 🎯 Features

* 💬 Chat with the bot
* 📝 Enter user messages
* 🤖 Automatic chatbot responses
* 👋 Responds to greetings
* ❓ Answers basic questions
* 🧹 Clear chat option
* 💻 Simple and user-friendly interface
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** – Creates the chatbot structure
* **CSS3** – Provides styling and layout
* **JavaScript** – Handles messages and chatbot responses

## 📂 Project Structure

Simple-Chatbot/

├── index.html

## 🚀 How to Run

### Step 1: Clone the Project

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open in VS Code

Open the **Simple-Chatbot** folder in Visual Studio Code.

### Step 3: Run the Project

Open `index.html` using **Live Server**.

### Step 4: Start Chatting

Enter a message in the chat box.

Example:

```text
User: Hello
Bot: Hello! How can I help you?

User: How are you?
Bot: I'm doing great! Thank you for asking.

User: What is your name?
Bot: I am a simple chatbot.
```

## 🎯 Objective

The main objective of this project is to create a simple interactive chatbot using **HTML, CSS, and JavaScript** and understand how user input can be processed to generate predefined responses.
